# Планировщик накоплений — полная настройка

Инструкция: как выложить планировщик в интернет (телефон, ноутбук, любая точка мира) и подключить Google Таблицу.

---

## Часть 1. Доступ из интернета

Планировщик — один файл `index.html` + папка `google-apps-script/`. Сервер не нужен: подойдёт любой **бесплатный хостинг статических сайтов**.

### Вариант A — GitHub Pages (рекомендуется)

1. Создайте репозиторий на [GitHub](https://github.com) (можно приватный).
2. Загрузите **всю папку** `finance-planner` (как корень репозитория или как подпапку).
3. **Settings → Pages**:
   - Source: ветка `main` (или `master`)
   - Папка: `/` (если репозиторий = планировщик) или `/finance-planner`
4. Через 1–2 минуты сайт будет по адресу:
   - `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`
5. Откройте ссылку на телефоне → добавьте в закладки или «На экран Домой».

> В репозитории уже есть файл `.nojekyll` — GitHub Pages отдаст все файлы, включая `google-apps-script/Code.gs`.

### Вариант B — Netlify (перетащить папку)

1. [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку `finance-planner`.
3. Получите URL вида `https://случайное-имя.netlify.app`.
4. В **Site settings → Domain** можно задать своё имя.

### Вариант C — Cloudflare Pages

1. [dash.cloudflare.com](https://dash.cloudflare.com) → Pages → Create project.
2. Подключите GitHub-репозиторий или загрузите файлы.
3. Build command: пусто. Output directory: `/` (корень планировщика).

### Важно

| Открытие | Google-синхронизация |
|----------|----------------------|
| `file://` (двойной клик по файлу) | ❌ часто не работает |
| `http://localhost:8080` | ✅ для разработки |
| `https://…` (GitHub Pages, Netlify…) | ✅ **нужно для телефона и работы из любой точки** |

Данные планировщика хранятся в **localStorage браузера** на каждом устройстве отдельно. Синхронизация между устройствами — через **Google Таблицу**.

## Часть 2. Google Таблица

1. [Google Таблицы](https://sheets.google.com) → **Создать** пустую таблицу.
2. Скопируйте **ID** из адреса:
   ```
   https://docs.google.com/spreadsheets/d/19Z93po1nU1W4VVfstmLR-RsQU5g6ePqjbfiuQCRl2kM/edit
                                         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                                         только эта часть
   ```

После синхронизации появятся листы:

| Лист | Содержимое |
|------|------------|
| **По_месяцам** | Доходы и расходы: строки = статьи, столбцы = месяцы |
| **Цели** | Цели, накоплено, приоритеты |
| **_meta** | Служебные настройки |

## Часть 3. Apps Script (мост)

1. В таблице: **Расширения → Apps Script**.
2. Скачайте `Code.gs` из планировщика (вкладка **Google Таблицы → Скачать Code.gs**).
3. Вставьте код в редактор Apps Script.
4. **Секреты — только в Script Properties** (не в GitHub, не в публичном коде):
   - В редакторе Apps Script откройте функцию `setupSecrets`, подставьте свои значения.
   - **Выполнить** `setupSecrets` один раз (Run).
   - Или вручную: **Project Settings** (шестерёнка) → **Script properties** → добавить:

| Свойство | Пример | Назначение |
|----------|--------|------------|
| `SPREADSHEET_ID` | `19Z93po1nU1W4VVfstmLR-...` | ID таблицы |
| `SECRET_TOKEN` | длинная случайная строка 32+ символов | Главный ключ API |
| `SYNC_PIN` | `847291` | Второй пароль (обязательно рекомендуется) |

5. **Сохранить** (Ctrl+S). Поля `SECRET_TOKEN` и `SPREADSHEET_ID` в файле `Code.gs` оставьте **пустыми**.
6. При первом запуске — разрешите доступ к таблице.

### Развёртывание веб-приложения

1. **Развернуть → Новое развёртывание** (или **Управление развёртываниями → Изменить**).
2. Тип: **Веб-приложение**.
3. Параметры:

| Поле | Значение |
|------|----------|
| Выполнять как | **Я** |
| У кого есть доступ | **Все** (Anyone) |

4. **Развернуть** → скопируйте URL (заканчивается на `/exec`).

После каждого изменения `Code.gs` — **новая версия** и снова **Развернуть**.

### Проверка

Откройте в браузере (подставьте свои значения):

```
https://script.google.com/macros/s/ВАШ_ID/exec?token=ваш-секрет&action=ping
```

Ожидается: `{"ok":true,"message":"pong"}`

## Часть 4. Подключение в планировщике

1. Откройте планировщик **по HTTPS-ссылке** (не `file://`).
2. Вкладка **Google Таблицы**.
3. Заполните:
   - **URL веб-приложения** — `/exec` из шага выше
   - **Секретный токен** — из Script Properties (`SECRET_TOKEN`)
   - **PIN синхронизации** — из Script Properties (`SYNC_PIN`)
   - **ID таблицы** — для справки
4. **Проверить подключение** → должно быть «Подключение OK».
5. **Выгрузить в Google** — полная выгрузка.
6. **Сохранить месяц в Google** (кнопка в шапке) — обновить колонку рабочего месяца на листе «По_месяцам».

---

## Часть 5. Телефон

1. Откройте HTTPS-ссылку планировщика в Chrome / Safari.
2. **Добавить на главный экран** (меню браузера).
3. Настройте Google один раз на телефоне — те же URL и токен сохранятся в localStorage телефона.

## Безопасность (публичный сайт на GitHub Pages)

**Публичный сайт ≠ доступ к вашей таблице.** Посторонний видит только интерфейс планировщика. Чтобы писать в таблицу, нужны **все три секрета**:

1. URL веб-приложения Apps Script (длинный, не угадывается)
2. `SECRET_TOKEN` (длинный случайный ключ)
3. `SYNC_PIN` (второй пароль)

Они хранятся в **Script Properties** в Google и в **localStorage вашего браузера** — не в репозитории GitHub.

Дополнительно:
- Google Таблицу **не открывайте** «всем по ссылке на редактирование»
- Не публикуйте URL + токен + PIN в чатах и скриншотах
- При утечке — смените `SECRET_TOKEN` и `SYNC_PIN` в Script Properties и переразверните веб-приложение

Полноценный вход через Google-аккаунт (OAuth) для статического сайта возможен, но сильно сложнее; для личного планировщика достаточно токен + PIN.

## Частые ошибки

| Ошибка | Решение |
|--------|---------|
| Failed to fetch | Открывайте по HTTPS, не `file://`. Доступ в развёртывании — «Все». |
| Invalid token | Токен в планировщике = `SECRET_TOKEN` в Script Properties. |
| Invalid PIN | PIN в планировщике = `SYNC_PIN` в Script Properties. |
| Файл не обнаружен | URL должен быть `script.google.com/macros/s/.../exec`, не ссылка на таблицу. |
| Sign in (вход Google) | В развёртывании выберите доступ **Все**, не «только я». |
| Illegal spreadsheet id | В `SPREADSHEET_ID` только ID, без `d/`, `/edit`, `gid`. |
