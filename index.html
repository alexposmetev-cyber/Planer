Подключение Google Таблицы

Не ссылка на таблицу! Берётся из Apps Script → Развернуть → Веб-приложение → URL (заканчивается на /exec).
Храните в Script Properties в Google (не в GitHub). Совпадает с SECRET_TOKEN в Apps Script.
Второй пароль — только у вас в планировщике и в Script Properties (SYNC_PIN). Без PIN посторонний с сайтом в таблицу не попадёт.
В скрипте — SPREADSHEET_ID в Script Properties.
Безопасность: публичный сайт ≠ доступ к вашей таблице. Нужны секретный URL веб-приложения + токен + PIN. Не публикуйте их и не коммитьте в GitHub. Таблицу в Google не открывайте «всем по ссылке».
Открыто как файл (file://) — синхронизация с Google может не работать. Запустите в папке проекта: python -m http.server 8080 и откройте http://localhost:8080.
Развёртывание: Выполнять как: Я, доступ Все (Anyone), URL с /exec. Подробно — в инструкции ниже.

Доступ из интернета и материалы

Чтобы открывать планировщик с телефона и ноутбука из любой точки мира — выложите папку проекта на GitHub Pages, Netlify или Cloudflare Pages. Синхронизация с Google работает только по https://, не через двойной клик по файлу.
