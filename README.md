# Планировщик накоплений

Интерактивный калькулятор: доходы, расходы, цели, прогноз на 24 месяца и синхронизация с Google Таблицей.

## Открыть локально

```bash
# из папки finance-planner (нужен Python или любой статический сервер)
python -m http.server 8080
```

Браузер: http://localhost:8080

## Доступ из интернета (телефон, ноутбук)

Выложите папку `finance-planner` на **GitHub Pages**, **Netlify** или **Cloudflare Pages**.

**Пошаговая инструкция:** [`НАСТРОЙКА.md`](НАСТРОЙКА.md)

В планировщике: вкладка **Google Таблицы** → кнопки **Скачать Code.gs** и **Скачать инструкцию**.

## Возможности

- **Рабочий месяц** в шапке со стрелками ‹ ›
- **Источники дохода** (несколько статей на человека)
- **Расходы** с историей по месяцам
- **Цели** с приоритетом и режимом «₽/мес» или «к дате»
- **Журнал отложений** и прогноз на 24 мес.
- **Google:** один лист `По_месяцам` (столбцы = месяцы), листы `Цели`, `_meta`

## Google — кратко

1. Таблица → Расширения → Apps Script → вставить `google-apps-script/Code.gs`
2. Секреты в **Script Properties** (`setupSecrets`): `SPREADSHEET_ID`, `SECRET_TOKEN`, `SYNC_PIN`
3. Развернуть веб-приложение: **Я** + доступ **Все** → URL `/exec`
4. URL и токен в планировщере → **Проверить подключение**

Подробности: [`НАСТРОЙКА.md`](НАСТРОЙКА.md)
