> **Актуальная пошаговая инструкция** (хостинг в интернет + Google): [`НАСТРОЙКА.md`](НАСТРОЙКА.md)  
> Скачать `Code.gs` и инструкцию: вкладка **Google Таблицы** в планировщике.

## Варианты (от простого к полному)

| Вариант | Сложность | Что даёт |
|---|---|---|
| **A. CSV вручную** | Уже работает | Кнопка «Скачать CSV» → Файл → Импорт в Google Таблицы |
| **B. Google Apps Script** | Средняя, без сервера | Таблица сама подтягивает JSON из браузера / наоборот |

## Вариант B — Google Apps Script (рекомендуется)

### Что нужно подготовить

1. **Google-аккаунт** с доступом к Google Drive.
2. **Новая Google Таблица** — например, «Планировщик накоплений».
3. **Структура листов** в таблице:

#### Лист `Доходы`
| A | B | C | D |
|---|---|---|---|
| Месяц | Зарплата_В | Зарплата_А | Итого |
| Июн 2026 | 91350 | 186041 | =B2+C2 |

#### Лист `Расходы_текущие`
| A | B |
|---|---|
| Категория | Сумма |
| Продукты | 25000 |
| … | … |

#### Лист `Расходы_история`
Столбцы = месяцы снимков (Июн 2026, Июл 2026…), строки = категории.

#### Лист `Цели`
| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| Название | Сумма_цели | Накоплено | Приоритет | Режим | Значение | Нужно_в_мес |
| Ипотека | 1500000 | 0 | 1 | monthly | 50000 | =ОСТАТ(B2-C2;F2) |
| Машина | 1300000 | 0 | 2 | date | 2028-06-01 | =ОСТАТ(B3-C3;ДАТАРАЗН(F3;СЕГОДНЯ();"м")) |

#### Лист `Прогноз`
Импорт CSV с вкладки «Прогноз» или формулы, ссылающиеся на другие листы.

### Шаги настройки

1. В таблице: **Расширения → Apps Script**.
2. Вставьте скрипт из файла `google-apps-script/Code.gs` (будет добавлен в проект).
3. **Развернуть → Новое развёртывание → Веб-приложение**:
   - Запуск от: **Я**
   - Доступ: **Все** (или только вы — тогда нужен токен в URL)
4. Скопируйте **URL веб-приложения** → вставьте в планировщер (вкладка «Google Таблицы»).
5. Скопируйте **ID таблицы** из URL:  
   `https://docs.google.com/spreadsheets/d/`**`ЭТОТ_ID`**`/edit`

### Как работает обмен

```
Браузер (index.html)  --POST JSON-->  Apps Script Web App  --write-->  Google Sheet
Браузер  <--GET JSON--  Apps Script  <--read--  Google Sheet
```

**Важно:** чистый `index.html` на диске не может напрямую писать в Google Sheets без OAuth или прокси (Apps Script). Поэтому Apps Script — это «мост» без своего сервера.

### Безопасность

- URL веб-приложения — как пароль: не публикуйте в открытом доступе.
- В скрипте можно добавить простой `token` в запросе.
- Данные о зарплате — чувствительные; таблицу не открывайте на редактирование всем.

## Вариант C — Google Sheets API (на будущее)

### Что понадобится

1. **Google Cloud Project** → [console.cloud.google.com](https://console.cloud.google.com)
2. Включить **Google Sheets API** и **Google Drive API**.
3. Создать **OAuth 2.0 Client ID** (тип: Web application).
4. Authorized JavaScript origins: `http://localhost` или URL, где открыт планировщик.
5. Подключить библиотеку `google.accounts.oauth2` в `index.html`.
6. При первом нажатии «Синхронизировать» — окно входа Google.

### Ограничения

- OAuth из `file://` (двойной клик по HTML) **не работает** — нужен локальный сервер (`npx serve`) или хостинг.
- Нужно хранить `client_id` (публичный) и настраивать redirect URI.

### Поля в планировщике (уже заложены)

- Spreadsheet ID
- Имена листов: Доходы, Расходы, Цели, Прогноз
- Кнопки: «Выгрузить в Google», «Загрузить из Google»

## Формат JSON для обмена

Планировщик экспортирует/импортирует единый объект:

```json
{
  "version": 2,
  "exportedAt": "2026-06-06T12:00:00",
  "defaultSalary": { "v": 91350, "a": 186040.8 },
  "incomeByMonth": { "0-5": { "v": 0, "a": 186040.8 } },
  "expenseCategories": [{ "id": "food", "name": "Продукты", "value": 25000 }],
  "expenseSavings": { "vacation": 8000, "repair": 8000 },
  "expenseHistory": [{ "label": "Июн 2026", "values": {}, "total": 103400 }],
  "goals": [{ "id": "mortgage", "name": "Ипотека", "target": 1500000, "planMode": "monthly", "monthlyAmount": 50000 }],
  "settings": { "allocationMode": "priority", "savePercent": 30 }
}
```

Кнопка **«Скопировать JSON»** на вкладке Google — для ручной вставки в Apps Script или отладки.
